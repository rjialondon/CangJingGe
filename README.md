# 藏经阁千字文导读

从《千字文》四字句进入相关典籍，原文、上下文、篇章与整书分片阅读。当前接通132处四字导读，另有1处八字合读，共借入21部馆藏书。第一轮已扫至第140句；容易贴合的先接，第17、35、38、111、112、116、125、126句留待第二轮。部分已接句仍有待寻支路，不以未接通冒称缺书，也不以可点击冒称全句已考定。

- [阅读页面](https://rjialondon.github.io/CangJingGe/)
- [自动核验与发布记录](https://github.com/rjialondon/CangJingGe/actions/workflows/qianzi.yml)

页面展示最近一次成功发布的馆藏快照，不在线读取本机文件。`main`更新后先核验，通过才发布；首次访问须等首轮发布完成。

《周易》导读绑定`房/易堂/四库易类/周易.md`的BGC／Kanripo馆藏工作本；《周易本义·道观正本》是道观内部经，不在本项目可绑定书目与发布范围内。

## 本机阅读

在本仓根目录执行（Python 3.10以上，无第三方包）：

```sh
python3 -B 房/蒙卷/卷册/千字文/预览.py --端口 0
```

打开终端打印的网址，结束按`Ctrl-C`；不要直接双击`页面/index.html`。古籍只从道观主阁同步，本副本不独立改书；项目完成后仅回流千字文项目，GitHub设施另留。
